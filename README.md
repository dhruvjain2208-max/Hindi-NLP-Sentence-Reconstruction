# Hindi NLP Sentence Reconstruction and Translation

## Overview
An NLP pipeline designed to process shuffled Hindi text.

## Objectives
1. Punctuation Restoration
2. Sentence Segmentation
3. Sentence Ordering
4. Grouping of Five Sentences
5. Hindi-to-English Translation

## Models Used
- Punctuation Restoration Small
- Multilingual MiniLM
- OPUS-MT Hindi-English

## Technologies
- Python
- PyTorch
- Hugging Face Transformers
- Sentence Embeddings
- Beam Search
